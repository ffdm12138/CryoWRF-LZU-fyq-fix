# Bug 13 吹雪微物理写回与嵌套边界非有限值

**状态**　写回修复已同步，生产跨风险窗继续观察。

## 现象与定位

嵌套边界出现非有限值。历史对照识别了吹雪微物理中未初始化的 `meanR` 写回和非有限粒子混合比泄漏。

## 修复

在 `phys/module_microphysics_driver.F` 设定确定的 `meanR` 默认值并拦截非有限的 `qi/qni` 写回。原诊断性探针由案卷单独追踪。

## 验收

原案检查中 `BS_MEANR` 的 NaN 和绝对值超过 10³⁰ 的计数分别从 952 和 7,327 降至 0。公开分支核对源码与原修复一致。全年边界风险窗需独立运行验证。
