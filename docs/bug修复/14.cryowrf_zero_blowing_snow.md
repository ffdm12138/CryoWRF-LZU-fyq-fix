# Bug 14 浅雪条件下吹雪恒零

**状态**　原物理模式十日窗口通过。

## 现象与定位

历史浅雪试验在风场具备起吹条件时，吹雪量仍持续为零。耦合层用实际雪深 `cH - Ground` 检查 0.5 m 门槛。Fortran 旧模式还应用独立的默认 0.2 m 雪深门槛。临界摩阻风速的单位为 m/s，由雪面状态参与确定。

## 修复

历史批次引入旧模式和物理模式开关，允许设置耦合层雪深门槛，并保持雪可用性与稳定性检查。物理模式跳过 Fortran 的旧雪深抑制，耦合层门槛仍可单独配置。

## 验收与后续

原物理模式十日算例出现持续吹雪，受检场的非有限值计数为零。后续拟在独立天气过程上验证降尺度分布，再分别比较两层雪深门槛及次网格摩阻风速。数值稳定性与等效雪盖覆盖率解释均为假设。公开基线兼容性见[发布回执](发布回执.md)。
