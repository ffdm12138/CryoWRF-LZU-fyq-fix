# SNOWPACK 官方简化冷初始化

## 现象与修订

旧生成器对土温样点和写出的土层数处理不一致。修订采用官方示例的简化初始化，输出完整的 30 层土壤剖面。土温由土顶向地表温度插值并截到冻结点，雪层筛选使用初始化专用的 3 cm 门槛。

入口为 `runtime/make_sno_from_met.py`，配套调用位于 `runtime/pipeline_metgrid_to_real.sh`。使用显式输入与输出路径，热续算继续从匹配检查点读取状态。公开管线默认从脚本同目录查找生成器，允许用 `PYTHON` 指定解释器、用 `SNO_GENERATOR` 指定生成器绝对路径。管线的文件数量门槛对应原三域算例。

## 验收

原试验逐列验收 42,768 个剖面，并完成原分区生产启动验收。生成器与原验收文件的 SHA-256 一致。公开管线替换了本机路径及案例注释，并通过 Shell 语法、默认路径和显式覆盖参数检查。该回执的科学范围为初始化与启动。
